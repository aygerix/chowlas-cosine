 Negative sublevels and the Chowla floor
 test
 Research report • 20 October 2026

 Main conclusion. The observed packet-versus-Boolean near-floor separation is real in the
 tested examples, but it is not a universal obstruction to hypothetical Chowla counterexamples.
 An exact Boolean augmentation can preserve a counterexample sequence while forcing every
 fixed-depth negative sublevel to have vanishing measure.

 Definitions and the question
 For a nonempty finite set A of positive integers, use normalized Lebesgue measure on ℝ/ℤ and
 define

                           fA(x) = ∑a∈A cos(2πax), MA = −min fA, RA = MA/√|A|,
                                 HA(t) = meas{x : fA(x) ≤ −tMA}, 0 < t ≤ 1.

 A hypothetical counterexample sequence means |A| → ∞ and RA → 0. The question is whether
 the shape of H, normalized by the true deepest minimum, distinguishes all such Boolean
 sequences from the P61(b) weighted packets. E125 uses N(s) = H(1 − s), so its N(0.01) is
 H(0.99).

 Exact finite Boolean augmentation lemma
 Let B be any nonempty finite set, let L ≥ 1 be an integer, and choose an integer q > max B. Put
 C = B ∪ {q, 2q, …, Lq}, gL(y) = ∑k=1L cos(2πky), and mL = −min gL. Then C is Boolean, |C| = |B|
 + L, and

                                  2L/(3π) ≤ mL ≤ MC ≤ mL + MB ≤ L + MB.

 Whenever 2(tmL − MB) − 1 > 0,

                                          HC(t) ≤ 1/[2(tmL − MB) − 1].

 Proof of the floor bounds
 Disjointness is immediate. The pointwise lower bound fC = fB + gL(qx) ≥ −MB − mL gives the
 upper bound on MC. If y is a minimizer of gL, root-of-unity averaging gives, for each a ∈ B,

                                     (1/q) ∑j=0q−1 exp(2πia(j + y)/q) = 0.

 Thus one of the q points x = (j + y)/q has fB(x) ≤ 0, while gL(qx) = −mL. Hence MC ≥ mL. No
 equidistribution limit or special choice of q is needed.

 Why the universal fixed depth test fails
 Completion of the finite proof
 The Dirichlet identity and the point y = 3/(4L + 2) give

                                     2gL(y) + 1 = sin((2L + 1)πy)/sin(πy),
                                   mL ≥ ½[1 + csc(3π/(4L + 2))] ≥ 2L/(3π).

 If f (x) ≤ −tM , then g (qx) ≤ −tm + M . Set a = tm − M . When 2a − 1 > 0, g (y) ≤ −a
     C         C         L           L     B              L    B                    L
 implies |sin(πy)| ≤ 1/(2a − 1). Writing d = dist(y, ℤ), the bound sin(πd) ≥ 2d puts this set in arcs
 of total measure at most 1/(2a − 1). The map x ↦ qx preserves measure. This proves the
 sublevel bound.

 Conditional closure theorem
 Suppose Bj is a hypothetical counterexample sequence, with nj = |Bj| and Mj = o(√nj). Choose
 integers Lj satisfying max(Mj, 1) = o(Lj) and Lj = o(√nj), and choose any qj > max Bj. The
 augmentation above satisfies

                                          RCⱼ ≤ (Lj + Mj)/√(nj + Lj) → 0.

 For every fixed δ > 0, eventually Mj ≤ δLj/(3π), and monotonicity gives

                                   supδ≤t≤1 HCⱼ(t) ≤ [2δLj/(3π) − 1]−1 → 0.

 The added Lj = o(√nj) frequencies are negligible in coefficient energy but dominate the
 minimum. A narrow negative trough therefore controls the normalization. If any
 counterexamples exist, there are counterexamples with vanishing fixed-depth H.

 Exact scope
 This is not an actual counterexample, a proof of Chowla, or a novelty claim. It blocks the
 assertion that every arbitrary hypothetical counterexample must have H(t₀) ≥ c > 0 at some
 fixed depth t₀. The original background can move into the boundary layer t ≍ Mj/Lj → 0.
 Scale-dependent depths and joint Boolean coefficient-energy inequalities are not excluded. No
 such new inequality is established here.

 The packet limit is nevertheless genuine
 For a fixed continuous compactly supported positive-definite kernel w with w(0) = 1, the P61(b)
 construction with J → ∞ and J/X → 0 obeys MX/√(J/8) → 1 and HX(t) → 1 for each fixed 0 < t < 1.
 This is a model-specific asymptotic, not a characterization of every obstruction. At t = 1, H = 0
 for each nonconstant trigonometric polynomial.

 How to read the evidence
 At half depth, the E125 packet and Singer–Bu profiles are comparable; close to the floor, the
 gap is large. Neither a finite-size gap nor a fitted near-floor power law supplies the missing
 universal implication. In particular, the exact augmentation theorem does not depend on the
 numerical examples.

 Proof details for the packet limit and the profile caveat
 Packet concentration for every fixed kernel
 Let W be the inverse Fourier transform of w. Positive definiteness gives W ≥ 0 and ∫W = 1. The
 periodized packet is S (x) = X∑      W(X(x + m)). Define T(r) = ∫       W(u)du → 0. Outside the
                        X        m∈ℤ                               |u|>r
 union of radius r/X arcs around the 2J translated or reflected packet centers, the average packet
 mass has integral at most T(r). Thus for η > 0,

                                meas{(∑ packets)/(2J) > η} ≤ 4Jr/X + T(r)/η.

 Choose r → ∞ with Jr/X → 0. This proves that the average packet tends to zero in probability,
 independently of the centers. Write B = √(J/8), c = 1/√(32J), and E = P + c∑ packets − B. The
                                                                    X   X
 smooth part satisfies P ≥ −1/4 and ∫P = 0, so (P + 1/4)/B → 0 in probability by Markov’s
                        X               X           X
 inequality. Consequently E /B → −1 in probability.
                                  X

 The global bound EX ≥ −B − 1/4 and convergence in probability imply MX/B → 1. Therefore
 EX/MX → −1 in probability, proving HX(t) → 1 for each fixed t < 1. For the triangular kernel T(r) =
 O(1/r); a general fixed kernel need not have that rate.

 A separate obstruction to a stable profile only discriminator
 Fix any nonempty Boolean A and its f, M. Choose q > max A and let KN(x) = (1/N)|∑k=0N−1
 exp(2πikx)|² be the Fejér kernel. For 0 < ε ≤ 1/2, define F = f + ε(KN(qx) − 1). The supports are
 disjoint and all coefficients lie in [0,1]. Its coefficient-square energy is

                                      E(F) = |A| + 4ε²(N − 1)(2N − 1)/(6N).

 Since KN ≥ 0 and ∫KN = 1, F ≥ f − ε and ‖F − f‖₁ ≤ 2ε. For U = {f < −M + δ}, with measure u >
 0, some x ∈ U has KN(qx) ≤ 1/u. Thus M − δ − ε/u ≤ MF ≤ M + ε, proving MF → M uniformly in N
 as ε → 0.

 Choose ε → 0 and Nε² → ∞. Then MF/√E(F) → 0 but F/MF → f/M in probability. Every level set of
 the nonconstant trigonometric polynomial f is finite, so its distribution is atomless. The
 distribution functions, and hence HF on [0,1], converge uniformly to HA.

 What this adds. Every fixed Boolean H-shape can be approximated uniformly by bounded fractional polynomials
 with diverging normalized energy. This does not match P61’s two coefficient profiles, nor rule out a genuinely
 Boolean energy theorem. It rules out treating stable H-shape separation alone as the required energy mechanism.

# Brief: G3 — is |B_t| <= C·K³ in every finite abelian group? (and an adversarial check of P21)

## Exact statement
Γ finite abelian, A = −A ⊂ Γ \ {0} a SET, F(χ) = Σ_{a∈A} χ(a) (real) and K := −min_χ F(χ) (all characters χ), t ∈ Γ,
B_t = {m ∈ A : m − t ∈ A, m + t ∉ A}.
**G3:** there is an absolute C with |B_t| <= C·K³ for all Γ, A, t.
Why it matters (verified in .research/PROOFS.md P19/P20): bounds valid in all Z_N transfer to Z (A ⊂ [−X, X] embeds in
Z_N, N > 4X + 4|t|, F-samples preserved, B_t unchanged). In Z, Shankar (arXiv 2609.05338) gives Σ_{t∈A}|B_t| >= T/3
and Roth gives T >= n²/K − nK, so some t has |B_t| >= n/(3K) − K/3. Hence G3 (even only for cyclic Z_N with A in an
interval of length N/2) ⇒ Chowla exponent 1/4: M(A) >> |A|^{1/4} (current record 1/5, Shankar; Bedert's Prop 7.3 gives
|B_t| << K⁴ in every group).

## Known (read PROOFS.md P19, P20, P21 and .research/agents/conjG_report.md)
- Lower constructions: P20 Thm 1 (agent conjG) |B_t| = K²(K−1) in F_p^{1+3a} (full cosets present); P21 (lead) in F_p^4:
  A = {x2 ≠ 0, x1x2 + N(x3,x4) ≠ 0} ∪ {x2 = 0, x1 ≠ x3x4²}, t = e1, every t-coset has exactly p − 1 points, K = 3p,
  |B_t| = p³ = K³/27. So the group exponent is in [3, 4]; G3 would be sharp.
- Upper results: P20 Thm 2: ord t = 3 ⇒ |D| − |E| <= (K + u0)³ (D, E = cosets of ⟨t⟩ meeting A in 2, resp. 1 point;
  |B_t| = |D|); Lemma 3 (coset-mean bound) and Prop 5 (S0 a subgroup ⇒ |B_t| <= 8K² + 3K).
- Barriers (conjG report §2): (i) any positive combination of fibre monomials U^a Ū^b c^d (Schur products of p.d.
  fibre transforms) has value +1 on singleton fibres, so it bounds |D| − ε|E|, never |D|; (ii) arguments seeing only the
  real-reduced functions 1_E − 1_D + K1δ0 and 1_E + 2·1_D + 3·1_F + K2δ0 cannot beat K⁴ (partial-spread example).
  So a proof of G3 must use the PHASE of the fibre transforms (Û >= −K at degree 1) or genuinely new structure.
- Diagnosis (P21): both K³ mechanisms use negative-definite fibres (fibre transform −e(jτ) at every j ≠ 0), which forces
  runs longer than ord(t)/2. In the Z-transfer every t-run is shorter than ord(t)/2.
- Z fibre transform (NOTEBOOK, lead): for A ⊂ Z, t >= 1, A_y = {k : y + kt ∈ A}, S_y(z) = Σ_{k∈A_y} z^k: for any z_i ∈ T
  with Πz_i = 1, Σ_{y=1}^{t−1} Π_i S_y(z_i) + Π_i (S_0(z_i) + K) >= 0.
